# Python - Inheritance

This repository covers the foundational and advanced concepts of Object-Oriented Programming (OOP) focusing specifically on Inheritance in Python 3.

## Requirements

* **Environment:** All scripts run on Ubuntu 20.04 LTS using `python3` (version 3.8.5).
* **Style:** Code complies strictly with `pycodestyle` (version 2.7.*).
* **Documentation:** Modules, classes, and functions must have descriptive docstrings without using forbidden keywords in comments.
* **Executables:** Every script must be executable.

## Tasks Summary

| Task | File | Description |
| --- | --- | --- |
| **0. Lookup** | `0-lookup.py` | A function returning a list of available attributes and methods of an object using `dir()`. |
| **1. My list** | `1-my_list.py` | A custom class inheriting from `list` with a specialized method to print sorted elements. |
| **2. Exact same object** | `2-is_same_class.py` | Validates if an object is an exact instance of a class, bypassing subclass checks via `type()`. |
| **3. Same class or inherit from** | `3-is_kind_of_class.py` | Checks if an object is an instance or inherited instance of a class using `isinstance()`. |
