The `MyList` class inherits from standard list and provides sorting utilities.

Standard usage and verification:
    >>> MyList = __import__('1-my_list').MyList
    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    
Testing the print_sorted method output:
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

Ensuring original list remains unmodified:
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Testing with negative integers and zeros:
    >>> new_list = MyList([-5, 0, -20, 15, 3])
    >>> new_list.print_sorted()
    [-20, -5, 0, 3, 15]
    >>> print(new_list)
    [-5, 0, -20, 15, 3]

Testing an empty list configuration:
    >>> empty_list = MyList()
    >>> empty_list.print_sorted()
    []
