# Python - Classes and Objects

This project is an introduction to Object-Oriented Programming (OOP) in Python 3. It covers the concepts of data abstraction, encapsulation, information hiding, and the implementation of private attributes, properties, getters, and setters.

## Learning Objectives

By the end of this project, you should be able to explain:
* What is Object-Oriented Programming (OOP).
* The difference between a Class and an Object/Instance.
* What is an attribute and how to use public, protected, and private attributes.
* What the special `__init__` method is and how to use it.
* The Pythonic way to write getters and setters using `@property`.
* What the `__dict__` of a class or instance contains.

## Requirements

* **OS/Environment:** Ubuntu 20.04 LTS interpreted with `python3` (version 3.8.5).
* **Style Guide:** Code strictly follows `pycodestyle` (version 2.7.*).
* **Executables:** All Python scripts must be executable (`chmod +x`).
* **Documentation:** Mandatory full docstrings for every module, class, and method.
