# Python - Input/Output

This project covers file handling operations in Python 3. It explores how to read and write files, handle file streams using the `with` statement, and utilize JSON serialization and deserialization techniques.

## Environment

* **OS:** Ubuntu 20.04 LTS
* **Interpreter:** Python 3.8.5
* **Style Constraints:** Strictly adheres to `pycodestyle` (version 2.7.*)

## Learning Objectives

* How to open, read, and write files using the `with` statement.
* Understanding JSON format, serialization, and deserialization.
* Accessing command-line parameters in Python scripts.

## Tasks Summary

| Task | File | Description |
| --- | --- | --- |
| **0. Read file** | `0-read_file.py` | Reads a text file (UTF8) and prints its content to standard output using the `with` statement. |
