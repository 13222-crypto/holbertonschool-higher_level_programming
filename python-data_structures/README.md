# Python - Data Structures: Lists, Tuples

## Description
This project is part of the Higher Level Programming curriculum at Holberton School. It covers the basics of data structures in Python, focusing specifically on Lists and Tuples.

## Learning Objectives
At the end of this project, you are expected to be able to explain:
- What lists are and how to use them.
- The differences and similarities between strings and lists.
- The most common methods of lists and how to use them.
- How to use lists as stacks and queues.
- What list comprehensions are and how to use them.
- What tuples are and how to use them.
- When to use tuples versus lists.
- What a sequence is.
- What tuple packing and sequence unpacking are.
- What the `del` statement is and how to use it.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.8.5)
- Code style: `pycodestyle` (version 2.7.*)

## Tasks
- **0. Print a list of integers**: A function that prints all integers of a list.
