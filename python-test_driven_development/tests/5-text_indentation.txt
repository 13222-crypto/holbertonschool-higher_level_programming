Using ``text_indentation``
--------------------------

Importing the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Normal text with expected triggers:
    >>> text_indentation("Hello. World? This is a test: Python is fun.")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
    This is a test:
    <BLANKLINE>
    Python is fun.
    <BLANKLINE>

Text with multiple continuous spaces after punctuation:
    >>> text_indentation("First.    Second?   Third:")
    First.
    <BLANKLINE>
    Second?
    <BLANKLINE>
    Third:
    <BLANKLINE>
