# Python - Everything is object

This project is dedicated to understanding how Python handles objects, references, mutability, and immutability.

## Answers Overview

* `0-answer.txt`: Function used to print the type of an object (`type`)
* `1-answer.txt`: Function used to get the variable identifier (`id`)
* `2-answer.txt`: Checks if two variables with different int values point to the same object
* `3-answer.txt`: Checks integer caching behavior for identical values
* `4-answer.txt`: Variable assignment pointing to the same object
* `5-answer.txt`: Variable reassignment with arithmetic operation
* `6-answer.txt`: String equality comparison using `==`
* `7-answer.txt`: String identity comparison using `is`
* `8-answer.txt`: String literal equality
* `9-answer.txt`: String interning/identity
* `10-answer.txt`: List content equality
