# JavaScript - Warm up

## Description
This project introduces JavaScript programming concepts such as variables, data types, conditionals, loops, functions, and process arguments execution using Node.js.

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`
* All files will be interpreted on Ubuntu 20.04 LTS using `node` (version 14.x)
* All files should end with a new line
* The first line of all files should be exactly `#!/usr/bin/node`
* A `README.md` file at the root of the folder of the project is mandatory
* Code should be `semistandard` compliant (version 16.x)
* All files must be executable (`chmod +x <filename>`)

## Tasks
* **0-javascript_is_amazing.js**: Script that prints "JavaScript is amazing" using `const`.
* **1-multi_languages.js**: Script that prints 3 lines using `console.log`.
* **2-arguments.js**: Script that prints a message depending on the number of arguments passed.
* **3-value_argument.js**: Script that prints the first argument passed to it without using `.length`.
* **4-concat.js**: Script that prints two arguments passed to it in the format " is ".
* **5-to_integer.js**: Script that prints "My number: <integer>" if the first argument can be converted to an integer.
* **6-multi_languages_loop.js**: Script that prints 3 lines using an array of strings and a loop.
* **7-multi_c.js**: Script that prints x times "C is fun" based on the first argument.
